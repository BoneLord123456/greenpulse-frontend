1. Since you have already unzipped the file...
			Move the folder "GreenPulse Project" to "~/Downloads/" if not already there

2. Make sure you are using Fish Terminal, and you are not on NEHU WIFI
									(stupid ass wifi, blocks important shit)

3. Open terminal, and run:
			```python ~/Downloads/GreenPulse\ Project/setup.py```

4. Next time, when you want to restart the servers, run:
			```python ~/Downloads/GreenPulse\ Project/start_greenpulse.py```

5. You can access the local website from ```http://localhost:5173```
